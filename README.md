# KillerPDF 1.9 Overkill

**Development build. This branch is not a stable release.**

KillerPDF 1.9 Overkill is under active development, with continuous work on The KillerPDF.Engine. Features, rendering results, and performance may change between commits.

## Ongoing engine work

The 1.9 engine handles PDF rendering, text extraction, document processing, and image decoding. Work is ongoing to improve rendering accuracy, compatibility, speed, and memory use.

Changes are tested against document corpora and the previous PDFium pipeline. Rendering differences and performance gaps are still being resolved. Overall parity with the previous engine has not yet been reached.
