MCP

Ask your agent to merge local PDF files with KillerPDF.

Install KillerMCP

KillerMCP includes all 81 KillerTools utilities plus tools from supported Killer apps in one local connection. You will not need a separate KillerPDF MCP installer, a source checkout, Node, or a list of commands.

Windows installer v0.1.0 coming soon
  1. Download and run KillerMCP Setup. The download button will appear here as soon as the signed public installer is released.
  2. Let setup connect your agent. It installs the shared runtime and registers KillerMCP with Codex, Claude Code, Claude Desktop, Cursor, GitHub Copilot, Gemini CLI, and Windsurf when found.
  3. Open a new agent chat and ask. KillerMCP detects KillerPDF on your computer and makes its PDF tools available through the same connection.

Try asking

killer is the shortest form. Your agent can infer KillerPDF when the request and attached files are clearly about PDFs. Use killerpdf only when you want to make the app explicit.

What it can do

KillerMCP can use the capabilities advertised by the installed KillerPDF version. It supports merging on the released 1.8 line, with preflight and accessibility reports when the installed build advertises those commands.

Merge two to eight PDFsCombine a short ordered list of local PDF files into one new document.
Keep the order you chooseThe output follows the input order supplied with your request.
Protect existing filesThe tool requires a new output path and refuses to overwrite an existing file.
Work on your computerKillerPDF reads and writes the files locally through the shared KillerMCP runtime.

Data safety and permissions

PDF operations run locally through the installed KillerPDF app. Merge creates one new output file and refuses to overwrite an existing file. Preflight and accessibility checks are read-only.

How it works

KillerMCP is a small program that lets your AI assistant use supported Killer apps installed on your computer. You install and connect it once, and it automatically finds the apps and tools available on your computer. When you ask your assistant to work with a PDF, KillerMCP checks the file locations and size limits, asks KillerPDF to perform the operation locally, confirms that it succeeded, and gives the result back to your assistant. The work is performed by the installed KillerPDF app, not by this webpage.

Current limits

Merge accepts 2 to 8 PDFs, each up to 64 MiB, with combined inputs up to 128 MiB. Reports accept one PDF up to 64 MiB when supported by the installed build. Password protected or damaged files may require KillerPDF directly. The public installer has not been released.

    One connection for the family

    Install KillerMCP once. It detects supported Killer apps on your computer and adds their tools to one agent connection. As more app integrations are released, the same KillerMCP runtime can provide them without a separate installer for every app.
